# 叙事结构选择

仅按项目类型选择最贴近的一种，再根据证据调整；不要机械套模板。

## 成长期硬科技 / 机器人 / AI

1. 赛道爆发 + 收入、订单或客户增长
2. 细分位置 + 全栈技术、核心部件、数据或规模壁垒
3. 顶尖团队 + 头部资本或产业资源

优先证明“需求已经发生”和“公司正在吃到增长”，不要只写宏大市场。

## 早期技术平台 / 新材料 / 制造工艺

1. 大市场 + 传统方案的明确痛点
2. 多年积累 + 技术或工程化突破
3. 客户验证 + 量产、成本或良率证据
4. 团队与资本（证据足够时保留）

优先解释为何过去做不到、现在为何能做成，以及量产证据。

## 生物医药 / 创新医疗器械

1. 未满足临床需求 + 可服务患者或市场空间
2. 核心技术平台 + 管线布局
3. 注册、临床或商业化进度
4. 科学家与产业化团队

准确使用临床分期与注册路径。不得把“预计完成二期”写成“即将获批”，不得把适应症市场规模直接等同于公司可实现收入。

## 消费硬件 / 科技出海

1. 品牌与渠道网络 + 覆盖国家、用户或客户
2. 已实现收入 + 新场景增长
3. AI/产品升级 + 新业务收入或验证
4. 创始人与全球化团队

区分 ToC 品牌资产、ToB 客户和渠道覆盖，不把“进入渠道”写成“终端销售”。

## 平台 / 数据 / 基础设施

1. 行业缺口 + 平台切入时点
2. 网络效应、数据飞轮或准入壁垒
3. 收入、节点、用户或生态伙伴验证
4. 团队与资本（可并入第三项）

用可量化的网络规模、数据获取成本、复用路径证明飞轮，避免只写“生态闭环”。

## 压缩判断

优先级通常为：已实现商业数据 > 可核验客户/订单 > 技术与资质 > 团队履历 > 市场预测 > 愿景。

同一事实只出现一次。若某项仅有愿景没有证据，把它放在段尾作为目标，或直接删除。
