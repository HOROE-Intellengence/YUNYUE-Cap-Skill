# 融资项目推介叙事框架库

以下四套框架来自不同类型的高转化项目推介。它们描述的是投资人先想确认什么、证据如何递进，不是行业标签、亮点清单或固定页数。先按主 skill 的“机会、势能、资格、复利、兑现”选择投资判断，再用本库选择最有冲击力的叙事路径。选择一个强起点，按材料自由删减、重排或组合；每一段都必须有事实支撑。

每套框架都按同一传播纪律工作：标题写最强可辩护的投资判断，不写原始事实标签；正文只保留决定性事实锚点。允许从相邻事实中向上提炼一层进攻性结论，例如由性能代差、客户进度与验证门槛推出“数月级先发窗口”；结论不必是材料原句，但必须能在 30 秒内讲清证据链。产品型号、客户地点、导入流程、完整技术参数和保密材料一律移入 BP 或 DD。

框架中的每个箭头节点代表一个候选投资问题，不代表可以合并成一句。成稿必须遵守“一段一问、事实独占”：市场窗口与订单验证分段，产品属性必须依次翻译为相对优势、客户利益和投资价值，团队履历不得与工程、供应链或交付能力串成一个复合判断。

## 1. 市场窗口 → 规模占位 → 闭环复利

**要赢得的判断**：公司已占住一个随产业放量而扩大的入口，未来不只卖单点产品。

**常见领衔模块**：机会或势能；以规模、复利作为后续证明。

**完整弧线**：

`产业或供给变化 → 当期增长/业绩拐点 → 已形成的规模入口 → 已跑通的商业闭环 → 数据、网络或跨品类复制`

**可用模块**：

- 市场为何在此刻扩张；
- 公司业绩是否已跟随放量；
- 用户、设备、站点、客户、交易频次或覆盖密度，证明“入口”已经形成；
- 买/卖/租/修/服务等闭环、单位模型、回本或利润，证明经济性成立；
- 数据沉淀、网络效应、相邻品类扩张，证明下一阶段的复利。

**避免**：没有规模入口或闭环事实时，不能把多产品罗列写成平台。

## 2. 人才组合 → 技术楔子 → 市场教育 → 验证到量产

**要赢得的判断**：稀缺团队不仅能做出关键技术，而且已经把它推向可规模化交付。

**常见领衔模块**：资格；以机会、势能和兑现证明技术并非停留在实验室。

**完整弧线**：

`为什么是这支团队 → 技术如何改变成本/体验/场景 → 市场窗口 → 试点、签约、收入或量产里程碑 → 更大规模路径`

**可用模块**：

- 创始人、科学家、连续创业者、产业老兵的具体履历与已验证成果；不得把履历直接翻译成未经证明的产品定义、算法、量产、供应链或交付能力串；
- 技术路线、系统或数据飞轮，说明客户结果和可迁移场景；
- 市场容量和采用趋势，解释需求端为何成熟；
- 从早期收入/盈利、标杆客户到量产、扩品类或多场景验证，说明商业化斜率。

**避免**：用名校、大厂或院士头衔替代产品验证；把签约、导入和量产混为一谈。

## 3. 刚性需求 → 系统护城河 → 标杆案例 → 准入能力

**要赢得的判断**：需求由政策、合规或关键任务推动，且公司有能力和资格进入高价值采购与交付场景。

**常见领衔模块**：机会或兑现；以资格和标杆案例证明高门槛需求能够被承接。

**完整弧线**：

`政策/风险/需求变化 → 一体化方案或系统能力 → 已完成的标杆案例与商业进展 → 专家团队、资质与产学研资源 → 可扩张市场`

**可用模块**：

- 政策、监管、风险事件或采购需求，证明窗口的紧迫性；
- 全链条方案、系统集成或关键技术，说明客户为什么不能用单点替代；
- 重大活动、重点客户、交付案例和收入/订单，证明可靠性与采购能力；
- 专家履历、准入资质、实验室或合作资源，说明进入门槛与交付资格。

**避免**：将政策预期写成已实现收入；将“参与/服务”模糊成正式采购或官方背书。

## 4. 高准入缺口 → 标杆收入 → 量化客户结果 → 复合交付团队

**要赢得的判断**：在难进入、难交付的垂直场景中，公司已凭标杆客户和量化结果跨过早期风险。

**常见领衔模块**：势能或兑现；以机会、资格和复利说明增长不会被轻易复制。

**完整弧线**：

`市场渗透缺口与准入门槛 → 标杆客户覆盖及收入增长 → 产品带来的效率/成本/质量结果 → 数据或平台持续迭代 → 懂场景且能交付的团队`

**可用模块**：

- 资质、资金、案例、部署、认证或替换成本，解释竞争为何不易进入；
- 标杆客户数量、收入、利润和增长，证明需求及商业化质量；
- 全栈系统、效率提升、客户节省、数据资产或平台能力，证明结果而非功能；
- 领域专家与技术/商业团队组合，解释从获客到部署、续约和扩张的闭环。

**避免**：只讲市场大和技术全，不交代客户结果或当期商业证明。

## 组合与取舍

- 不要求每个项目选择唯一框架。可用框架 2 的团队开局，接框架 4 的客户收入证明；也可用框架 1 的规模入口，接框架 3 的准入壁垒。
- 一个成稿通常保留 3–4 个主亮点。每个亮点只解决一个投资问题；同一事实不在多段重复承担不同结论。
- 相邻节点不能因为存在因果关系就自动合并；只有同一 FAB-F 链中的属性与直接结果可以留在同一段。
- 不要把框架写成谨慎摘要。每段用 1–2 条硬事实支撑一个性感但可守的结论；禁止编造数字、偷换客户状态或用“弯道超车、行业领先”等无比较口径口号代替推断。
- 先选最强投资判断作为开头，再安排决定性证明与持续性解释；不要为了框架完整而牺牲项目自己的证据顺序。
- 市场、技术、团队、案例、订单和融资均可成为开场，但只有能最快完成“3秒理解、5秒兴趣、15秒复述”的内容才应占第一亮点。
