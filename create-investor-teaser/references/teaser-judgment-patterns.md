# 推介图投资判断框架库

先识别项目正在从什么状态走向什么状态，再选择投资判断并将其压缩为一张图的视觉层级。四套路径不是行业模板，也不要求唯一选择；一个项目可用其中一套开场，借另一套的证明模块。主画面只保留能完成“3秒理解机会、5秒看见变化、15秒复述外部驱动如何传导为客户需求、公司兑现与持续性”的内容。材料只能证明静态优势时，表达优势本身，不制造增长拐点。

## 五类判断模块

- **机会**：赛道、供需缺口、政策、结构性窗口；
- **势能**：收入、合同、订单、客户、量产、增长阶段；
- **资格**：技术性能、产品突破、行业位置；
- **复利**：平台、数据、闭环、复制、切换成本；
- **兑现**：团队、资质、交付、案例、融资阶段。

每个模块上图时都使用：`投资判断 → 一条决定性证明 → 商业含义`。技术参数、客户地点、产品型号、导入步骤等原始事实只有在能证明上述判断时才保留。

## 1. 市场窗口 → 规模占位 → 闭环复利

**主判断**：公司已占住随产业放量而扩大的入口，未来不只卖单点产品。

`产业或供需变化 → 客户需求扩张 → 公司当期增长/规模入口 → 闭环或单位经济 → 数据、网络或跨品类复制`

视觉上用“机会或增长”作主标题；规模密度和闭环数据做证明；数据/复制机制放在持续性区。没有真实规模入口或闭环事实时，不使用平台化结论。

## 2. 人才组合 → 技术楔子 → 验证到量产

**主判断**：稀缺团队已把关键技术推向可规模化交付。

`团队与资格 → 技术改变的客户结果 → 市场窗口 → 从验证到签约、收入或量产的阶段跃迁 → 规模路径`

视觉上以“进入资格”或“技术突破的商业含义”领衔；用一项客户验证或量产节点证明；团队履历仅保留能解释产品定义、量产或交付能力的部分。

## 3. 刚性需求 → 系统护城河 → 标杆案例 → 准入能力

**主判断**：需求由政策、合规或关键任务推动，公司具备承接高价值采购的能力。

`需求或政策变化 → 高价值采购需求 → 系统能力 → 标杆案例与当期兑现 → 专家、资质与交付能力 → 市场扩张`

视觉上将政策与需求压缩为“刚性窗口”；将案例翻译为可靠性或采购验证；资格与团队承担准入证明。不要把参与经历写成采购或官方背书。

## 4. 高准入缺口 → 标杆收入 → 客户结果 → 复合交付团队

**主判断**：公司已跨过高准入行业的早期风险，增长具备客户结果与交付能力支撑。

`高准入缺口 → 从验证到订单/收入的商业跃迁 → 标杆客户与量化结果 → 数据或平台持续迭代 → 执行能力`

视觉上将客户数量、收入和客户结果合成一项商业证明；技术模块只解释效率、成本、质量或留存结果；团队模块证明从获客到部署和扩张的闭环。

## 原始事实的翻译

```text
多基地导入 → 客户部署具备复制能力
横向分辨率提升至多68倍 → 国产设备具备切入高端替代的性能资格
单笔超千万元采购 → 客户采购强度与订单放量证明
当期合同增长并出现复购 → 商业化由验证走向放量（只据合同与复购写订单或商业化，不写收入爆发）
多个 SKU → 平台化扩品空间（仅在产品确有共用技术、客户或数据基础时）
```

若翻译后仍不能改变“值不值得看”的判断，不进入主画面。
