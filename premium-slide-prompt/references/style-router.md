# Style Router

Select visual expression after choosing the page mode. Keep structure and style independent: the same page mode may use different expressions, and one expression may serve several page modes.

## Contents

- Routing sequence
- Visual expressions
- Page temperature
- Material budget

## Routing sequence

Decide in this order:

1. Identify what must carry the page: evidence, mechanism, momentum, scene, or corporate ceremony.
2. Select one primary expression from the five below.
3. Set one page temperature: Quiet, Standard, or Hero.
4. Allocate a material budget appropriate to that expression and temperature.
5. Check the previous and next pages when available; change expression or temperature when repetition weakens the deck.

Do not select a visual expression merely because the company belongs to technology, AI, semiconductor, healthcare, or another fashionable category.

## Visual expressions

### Quiet Evidence

Use when numbers, tables, credentials, comparisons, people, sources, or diligence-grade proof must carry the page.

- Lead with typography, data, rules, tables, or restrained evidence cards.
- Keep figurative imagery at roughly 0–20% of the canvas unless one real product image verifies the evidence.
- Prefer flat or low-depth containers; allow no-container editorial composition.
- Use whitespace and alignment instead of atmospheric effects.
- Default to Quiet temperature; use Standard only when one result deserves stronger emphasis.

Typical pages: investment highlights, competition, finance, team, financing, qualifications, rigorous comparison, and evidence portfolios.

### Scientific Mechanism

Use when a real system, causal chain, technical architecture, product structure, production process, or data loop explains why an outcome occurs.

- Build a coherent topology, layer stack, cutaway, process chain, or proof-bearing mechanism.
- Use arrows only for real sequence, dependency, feedback, or value transfer.
- Allocate roughly 25–45% of the canvas to technical or product visuals when they carry explanation.
- Let labels describe causes, transformations, and outcomes rather than nouns alone.
- Default to Standard temperature; use Hero only for one truly decisive technical page.

Typical pages: technology moat, algorithm, product architecture, manufacturing chain, data flywheel, and capability progression.

### Commercial Momentum

Use when direction, scale-up, commercialization, rollout, capital progression, or repeated replication is the central message.

- Use growth curves, steps, roadmaps, adoption paths, product matrices, or stage-gated progressions.
- Allow restrained porcelain-like 3D information forms when they make progression easier to read.
- Distinguish historical facts, current facts, targets, and FA scenarios visually.
- Keep one directional movement; do not turn every metric into a trophy object.
- Default to Standard temperature; use Quiet for financing or forecast pages that need caution.

Typical pages: market growth, revenue path, commercialization, development roadmap, capacity ramp, and capital progression.

### Strategic Hero

Use when one scene, product, contrast, or physical metaphor must create the deck's memory peak.

- Let one coherent scene or hero object occupy roughly 40–60% of the canvas.
- Keep one strong conclusion and only a few capital labels or evidence hooks.
- Allow higher contrast, reverse color, cinematic depth, or stronger lighting within the material budget.
- Make the image carry evidence, explanation, or a distinctive memory—not generic category atmosphere.
- Limit a normal investor deck to roughly 2–4 Hero pages unless the user explicitly requests a visual-led deck.

Typical pages: cover, Why Now, strategic positioning, major section turn, decisive technical breakthrough, and terminal vision.

### Corporate Ceremony

Use only for explicit corporate-brand, FA-brand, thank-you, partnership-ceremony, or formal closing pages.

- Permit brand landscape imagery, formal gold accents, logo walls, contact blocks, and QR codes when supplied.
- Keep hierarchy ceremonial but credible.
- Never use medals, laurels, shields, mountains, or gold merely to simulate evidence or prestige.
- Do not use this expression for project evidence pages by default.

## Page temperature

Temperature controls intensity, not structure.

| Temperature | Typical image share | Effects ceiling | Use for |
|---|---:|---:|---|
| **Quiet** | 0–20% | 0–5% | Finance, comparison, team, financing, qualifications |
| **Standard** | 15–40% | 5–12% | Market, product, technology, commercial model, roadmap |
| **Hero** | 40–65% | 10–20% | Cover, strategy, decisive transition, terminal vision |

Treat these percentages as compositional guidance, not arithmetic quotas. Lower intensity whenever evidence density or readability demands it.

Avoid three consecutive Hero pages. Avoid four consecutive pages with the same container grammar. A useful default rhythm is:

`Hero -> Quiet or Standard -> Quiet -> Standard -> Hero`

## Material budget

Set an internal budget for every slide:

```text
figurative_image_budget
technical_visual_budget
three_dimensional_object_budget
glass_container_budget
gradient_budget
lighting_budget
decorative_texture_budget
```

Use these default ceilings:

- **Figurative image:** zero when it does not provide evidence, explanation, category recognition, or memory.
- **Technical visual:** allow one coherent system rather than scattered components.
- **3D objects:** usually one primary object or one unified object system; avoid multiple decorative props.
- **Glass containers:** zero by default; allow one coordinated container family when material hierarchy benefits.
- **Gradients:** use for zoning, direction, material, or depth; never as a substitute for composition.
- **Lighting:** concentrate on the memory anchor or hero object; do not outline every element.
- **Decorative texture:** keep at zero unless it supports industry, space, scale, or material recognition.

Set the default budget for generic shields, globes, trophies, medals, laurels, floating chips, glowing pedestals, and circuit decoration to zero.

## Recommended mappings

Use these as defaults, not hard bindings:

| Page mode | Default expression | Optional upgrade or alternative |
|---|---|---|
| Investor-cover | Strategic Hero | Quiet Evidence |
| Investment-highlight-grid | Quiet Evidence | Commercial Momentum |
| Argument-map | Quiet Evidence | Scientific Mechanism |
| Evidence-portfolio | Quiet Evidence | Commercial Momentum |
| Conclusion-number | Quiet Evidence | Commercial Momentum |
| Rigorous-comparison | Quiet Evidence | — |
| Capability-progression | Scientific Mechanism | Commercial Momentum |
| Capital-progression | Commercial Momentum | Quiet Evidence |
| Capability-structure | Quiet Evidence | Scientific Mechanism |
| Causal-mechanism | Scientific Mechanism | Strategic Hero |
| Visual-metaphor | Strategic Hero | — |

## Corporate Ceremony gate

Before selecting Corporate Ceremony, require an explicit page function such as FA branding, thank-you, formal partnership, contact, or corporate identity. Otherwise route the page to Quiet Evidence, Commercial Momentum, or Strategic Hero according to its actual evidence task.
