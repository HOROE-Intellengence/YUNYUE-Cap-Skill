# Neutral Visual Foundation

Apply this foundation to every slide after selecting page mode, visual expression, temperature, and material budget. Keep it brand-neutral; let the mother style and observed brand DNA provide personality.

## Canvas and grid

- Use a 16:9 landscape canvas at high resolution.
- Use deliberate outer margins, a stable headline zone, and an alignment grid appropriate to the content density.
- Keep sources, qualifiers, and page furniture inside safe margins.
- Use asymmetry only when it improves reading order or emphasis.

## Typography

- Render supplied Chinese or English text cleanly in a modern, audience-appropriate type character.
- Make the conclusion headline unmistakable while allowing one decisive number, comparison, or object to outrank it.
- Use a small, controlled hierarchy of headline, evidence label, body, unit, status, and source styles.
- Preserve units, dates, qualifiers, asterisks, brackets, and data-status labels.
- Avoid excessive bolding, decorative display type, and mixed font personalities.

## Palette

- Use 1–3 semantic hue families in most slides; allow a fourth only when comparison or status requires it.
- Keep text and evidence contrast accessible.
- Assign colors by meaning and reuse those meanings across the deck.
- Treat white, black, gray, and tonal variations of one hue as neutrals rather than additional hue families.
- Never infer that technology must be blue, healthcare must be green, or premium must be gold.

## Containers and rules

- Use containers only to group evidence or control comparison.
- Permit open editorial layouts, tables, columns, bands, and diagrams without cards.
- Keep corner language, border weight, internal padding, and shadow depth consistent when containers repeat.
- Repeat identical internals only when exact comparison benefits.

## Diagrams and charts

- Choose the simplest visual form that preserves the logic and quantities.
- Use arrows only for sequence, dependency, feedback, value transfer, or intentional directional emphasis.
- Keep chart axes, scales, units, dates, and comparisons mathematically honest.
- Let one coherent system replace scattered decorative nodes.

## Images and objects

- Assign every image or object a role: evidence, explanation, category recognition, or memory.
- Match visual specificity to evidence specificity. Use precise cutaways only when the technical explanation supports them.
- Keep category-recognition imagery subordinate unless it is the selected memory anchor.
- Do not use generic chips, globes, shields, trophies, circuitry, or silhouettes as default decoration.

## Effects

- Use depth, gradients, glass, 3D, texture, and lighting only within the selected material budget.
- Concentrate effects around the primary anchor rather than distributing them evenly.
- Remove any effect that does not improve hierarchy, recognition, explanation, or atmosphere.
