# BP 披露与 DD 材料表

## 同源、分流

BP 与 DD 必须从同一 Claim–Evidence Graph 派生：

- **BP**：只展示建立兴趣、确信和行动所需的证据。
- **DD**：保存完整来源、日期、计算、口径、保密凭证、证据状态和追问接法。

不要先写 BP 再凭记忆补 DD，也不要因 DD 有材料就默认可上片。

## DD 材料表

| 字段 | 内容 |
|---|---|
| 对应页面 / 主张 | 支撑哪一页、哪句话或哪个数字 |
| 数字身份 | 事实 / 推断 / FA上行情景 / 待研究 |
| 完整来源与日期 | 报告、合同、订单、访谈、数据库或公司材料 |
| 计算与口径 | 起止年份、周期、公式、单位、区域和关键假设 |
| 保密状态 | 可公开 / 匿名展示 / 仅尽调披露 / 禁止对外 |
| 证据状态 | 已取得 / 可取得 / 待补 |
| 追问接法 | 能回答到什么程度、下一步提供什么材料 |

## 掩码纪律

- 匿名名称、区间、占位符和掩码必须原样保留。
- 不依据上下文恢复客户、合同金额、地点或机构关系。
- 仅 DD 的证据可以支持 BP 中的匿名结论，但不能借此泄露可识别细节。

## 融资披露红线

- 融资页默认只披露融资额与资金用途。
- 不主动展示投前/投后估值、估值区间、出让比例、单价或可反推估值的信息。
- 不主动补充轮次、交易结构和投资人权益；用户明确提供并要求展示时再处理。
- 可用商业模式、生态位、资产属性和资本市场对标建立价值想象，但不计算本项目当前估值。

发现疑似敏感披露时，先移入 DD 或改为安全占位；若无法判断，保留掩码并标 `[需复核]`，仍然交付大纲。
