## 通用 Page Spec

```text
### P{N} · {页面功能}
- 页面职责：[放大回报上限 / 降低失败概率 / 制造投资紧迫性 / 建立认知框架 / 推动交易行动]
- 投资任务：本页提高什么确信，或消除什么疑虑
- 核心结论：投资人必须记住的一句话
- 标题：中文定稿文案，直接上片
- 模块1：{证据载体/容器类型} | 内容
- 模块2/3/4/5：按需使用，总数不超过 5 个
- 容器规划：N 个主内容容器（≤5）| 各自的信息职责及共同结构
- 容器外文本：标题块；可选结论带；Logo/页码；底注
- 数字身份（后台）：[事实 / 推断 / FA上行情景 / 待研究]；仅在可能误读时上片
- 视觉锚点：[单锚点 / 四卡受控钩子 / 五项等权]
- 页面模式：[资本封面 / 投资亮点总览 / 竞争力目录 / 结论数字 / 严谨比较 / 资本演进 / 能力沿革 / 能力结构 / 因果机制 / 视觉隐喻]
- 投资人追问：看完后最可能追问什么
- DD材料：对应材料、证据状态、保密状态和追问接法
- 底注：来源、口径或必要解释
- 待补数据：
```

`页面职责` 来自 Deck Architecture；`页面模式` 根据证据结构单独选择，不固定绑定。

## 资本封面

封面只用大标题定义投资价值，用资本标签建立可信度，不写产品介绍。融资轮次必选；未提供则写 `[待补融资轮次]`。赛道、财务、团队、客户或资本背书只保留 2–4 个最强标签。

```text
### P1 · 资本封面
- 投资任务：3秒内建立项目级别、融资阶段和最强可信度
- 大标题：
- 公司名/Logo：
- 资本标签1：融资轮次（必选）
- 资本标签2–4：只选最强赛道 / 财务 / 团队 / 背书
- 资本凭证带：可选；团队 / 订单 / 资本背书中的 2–3 个短钩子
- 右侧拟物：对象 | 它证明什么
- 页面模式：资本封面
- 待补数据：
```

禁止使命愿景、功能清单、长副标题和弱标签。拟物对象必须有投资含义，不为科技感凭空造物。

## 投资亮点总览

固定覆盖市场上限、技术稀缺性、商业兑现和团队可信度。每模块采用 `短结论 → 1–3 条证明`；证据不足就标 `[待补数据]`，不以弱事实凑齐。每卡只保留一个主数字或主断言。

```text
### P{N} · 投资亮点总览
- 投资任务：用一页建立市场、能力、兑现与团队的组合确信
- 核心结论：
- 标题：产业触发 → 新机会 → 项目能力 → 商业结果
- 模块1：市场证据 | 短结论；1–2条证明
- 模块2：技术证据 | 短结论；1–3条证明
- 模块3：兑现证据 | 短结论；增长或客户证明
- 模块4：团队证据 | 短结论；能力组合；1–2条资历证明
- 容器规划：4 个主内容容器（≤5）
- 容器外文本：标题块；Logo/页码；底注；可选结论带
- 数字身份：
- 受控钩子：四卡各一个
- 页面模式：投资亮点总览
- 投资人追问：
- 底注：
- 待补数据：
```

## 核心竞争力地图

该页建立认知框架，不要求当页完成证明；允许五项等权，后续逐项兑现。

```text
### P{N} · 核心竞争力地图
- 页面任务：提前建立后续论证框架，降低理解成本
- 总结论：
- 竞争力1–5：短标签＋投资含义
- 后续对应页：
- 页面模式：竞争力目录
```

## 容器纪律

- 每页最多 5 个主内容容器。卡片、表格、面板、图表，以及共享主轴或阅读逻辑的时间轴、流程和比较结构均计作容器。
- 同一表格单元格、同一时间轴阶段和同一图表系列不分别计数。
- 标题块、Logo/公司名、页码、来源底注不计；结论带最多一个，不能再承载一组并列证据。
- 无法收束在 5 个容器内时先合并为表格、时间轴、矩阵或组合图，仍拥挤则拆页。
- 容器外只允许一个标题块、Logo/页码、来源与必要底注、可选一个结论句。关键数字、断言、解释、模块标题和图注必须进入结构或绑定图形。
- 禁止页顶、页中、页底同时散落多组裸排指标、独立小标题和悬浮结论。
