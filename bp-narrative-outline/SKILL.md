# BP投资叙事大纲生成器（Step 2 of 3）

工作流：读取材料与锁定叙事（Step 1）→ **生成投资人大纲（本 skill）** → premium-slide-prompt 生成美工提示词（Step 3）。

## 目标：建立投资确信

把BP写成一条投资确信链，而不是项目说明书或消费者广告。普通证据页只完成以下任务之一：

1. 放大回报上限；
2. 降低失败概率；
3. 制造投资紧迫性。

另有两类明确页面职责：

4. **建立认知框架**：目录、竞争力地图和章节过渡；
5. **推动交易行动**：融资页。

投资亮点总览是上述单任务原则的特殊页例外：它必须在一页内同时覆盖市场上限、技术稀缺性、商业兑现和团队可信度四类证据，用组合证据快速建立全局确信。目录、章节和交易页承担导航或行动职责，不因未独立完成前三项投资任务而删除。

普通证据页必须推进确信；目录、章节和交易页必须改善理解路径或下一步行动。用一句核心投资叙事统领全 deck。

核心原则：BP不必展示全部证据，但FA内部必须知道证据是否存在、材料存放在哪里、投资人追问时如何接住。完整来源、计算过程、保密信息和尽调凭证进入DD材料表，不因未上片而丢失。

## 先做判断，再写大纲

1. 先读取用户提供的全部文件、历史材料和可用知识库，不要询问材料中已有的信息。
2. 若用户已锁定核心叙事，检验其证据基础；不可靠时直接指出并提出更强版本。
3. 若用户未锁定核心叙事，不要停下等待。提出 2–3 个候选投资叙事，分别说明最强证据、最大短板和适配投资人；选择证据基础最强的版本生成 v0。只有不同选择会实质改变融资方向时，才请用户拍板。
4. 优先使用项目最硬、最意外、最能改变投资判断的证据开场。不要机械套用固定目录。

## 投资委员会六问

整套BP必须回答：

1. **市场够不够大？**
2. **为什么是现在？**
3. **为什么本项目能切进去？**
4. **为什么别人追不上？**
5. **为什么这个团队能兑现？**
6. **投资回报上限在哪里？**

交付前检查六问覆盖度。缺少证据时标记，不用形容词糊过去。

## 五种开局

根据最强证据选择一种，不强制反共识：

- **市场重估型**：原本有限的市场因结构变化迅速扩大。
- **资本验证型**：相邻公司估值快速跃迁，而本项目占据未覆盖位置。
- **技术断点型**：旧路线触及物理或经济极限，新路线首次可行。
- **兑现结果型**：订单、收入、客户或产品数据足够强，先亮结果再解释。
- **反共识型**：行业存在可被证据推翻的普遍误判。

反共识必须由商业结构或数据支撑；“所有人都错了”不是证据。

## 前五页五秒规则

前五页合计必须至少完成以下三件事：

1. 说明这是什么级别的机会；
2. 给出一个非看不可的产业变化；
3. 给出一个已经兑现的证据；
4. 建立团队或资本可信度；
5. 留下一个值得约谈才能回答的问题。

## 封面：一眼形成资本判断

封面只承担两件事：用大标题定义投资价值，用资本标签给出可信度。不要把封面写成产品介绍页。

### 文案结构

- **大标题**：一句投资结论或价值定位，优先回答“这是什么级别的机会”，不要写“致力于”“赋能”“领先解决方案”等空话。
- **资本标签**：融资轮次必须出现；其余标签只在能形成亮点时选用。通常保留 2–4 个，写成短标签，不写解释段落。

资本标签按优先级筛选：

1. **融资轮次（必选）**：如“Pre-A轮融资”“A轮融资”。材料未提供时写 `[待补融资轮次]`，禁止猜测。
2. **行业赛道（可选）**：必须具体到能体现稀缺性的细分赛道，避免只写“人工智能”“新能源”等大词。
3. **财务指标（可选）**：收入、利润、在手订单、装机量或业务规模；只使用亮眼且口径明确的数据，标注周期和单位。
4. **团队标签（可选）**：如“大疆团队”“华为团队”“行业20年老兵团队”；只有真实且足以降低执行风险时使用。
5. **背书标签（可选）**：客户背书如“华为供应商”，资本背书如“创东方领投”；必须核实关系和准确措辞。

除大标题、公司名/Logo与资本标签外，允许一行资本凭证带，用团队、订单或资本背书等 2–3 个短钩子快速建立可信度。禁止使命愿景、产品说明、功能清单和长段落。弱标签宁可不写，不能为了凑齐五类而稀释封面。

### 构图交接

- 页面模式固定为 `资本封面`。
- 大纲只指定拟物对象及其投资含义，不要求为了科技感凭空造物。

封面专用输出：

```text
### P1 · 资本封面
- 投资任务：3秒内建立项目级别、融资阶段和最强可信度
- 大标题：
- 公司名/Logo：
- 资本标签1：融资轮次（必选）
- 资本标签2–4：仅选择最亮眼的赛道 / 财务 / 团队 / 背书
- 资本凭证带：可选一行，包含团队 / 订单 / 资本背书中的 2–3 个短钩子
- 右侧拟物：对象 | 它证明什么
- 页面模式：资本封面
- 待补数据：
```

## 五组核心论证

### 1. 市场天花板

优先展示最有冲击力的市场天花板与形成原因。根据材料成熟度建立四级口径：

- TAM：理论总市场；
- SAM：项目实际可服务市场；
- 初始楔子市场：未来 3–5 年最可能拿下的部分；
- 价值迁移：预算为什么从旧方案流向新方案。

BP市场页可以只展示最有冲击力的市场天花板、增长方向和形成原因，不强制把 TAM、SAM、初始楔子和价值迁移全部塞入一页。完整分层口径、假设、计算和来源进入DD材料表。页面数字仍须保留必要的年份、区域、口径或预测提示，避免把推断写成历史事实。

### 2. 资本市场验证

同时寻找三类对标：

- 业务对标：解决相似问题；
- 资产对标：拥有相似的数据、设备、网络、标准或基础设施属性；
- 成长路径对标：经历过相似的“单点产品 → 平台 → 基础设施”过程。

允许展示竞对或相邻公司的融资、估值、市值、并购和估值跃迁，但必须尽量呈现：

`时间 → 业务里程碑 → 资本事件/估值 → 跃迁原因`

不要用“竞对值100亿，所以本项目值30亿”的粗暴算术。让对标证明未来价值形态，不主动计算本项目当前估值。

### 3. 成长路径双证据

当项目拥有 3 年以上连续技术、产品或客户积累时，检查是否能组成一对相邻页面：

1. **内部能力沿革**：证明项目有资格走这条路；
2. **外部终局对标**：证明这条路值得资本下注。

内部沿革不能写成成立、融资、获奖、发布产品等公司大事记。每个阶段都要回答：

- 新增了什么关键能力；
- 继承了什么稀缺资产；
- 解决了什么产业化缺口；
- 为下一阶段创造了什么条件。

优先提炼：

`技术底座 → 产品/设备化 → 能力展开 → 平台或标准`

外部对标则提炼：

`单点能力 → 客户共研 → 平台扩张 → 产业基础设施`

把两页连接成：

`内部路径证明“为什么能” → 外部先例证明“最终值多少想象力”`

允许战略性重复：一页用外部对标证明终局价值，另一页用公司路径说明如何走过去。两页必须回答不同问题，不能只是更换措辞和版式。

若使用高校、实验室、企业或合作方名称与 Logo，必须核实真实关系，避免暗示未经证实的技术转让、官方背书或机构隶属。若主张“同一技术底座连续演进”，必须点明被继承的具体资产，不只画一条连续线。

### 4. 进攻与防守

内部分析严格区分：

- **进攻楔子**：性能、成本、效率、新场景或交付优势，解释为什么能赢得第一批客户。
- **复利护城河**：数据累计、客户共研、工艺参数、认证周期、软硬耦合、供应链经验、现场样本、标准制定权和切换成本，解释为什么追赶越来越难。

技术参数必须翻译为：

`技术变化 → 客户结果 → 商业价值`

专门论证护城河时必须证明优势随时间加深，可用：

`护城河强度 = 稀缺资产 × 累计时间 × 切换成本`

总览页可以把进攻优势与复利壁垒合并表达为“复合竞争优势”，但不能把短期性能或成本优势直接称为永久壁垒。明年可能被复制的优势是进攻武器，不是护城河。

### 传播型公式

允许使用跨量纲的传播型公式，把多项优势收束为定性结论，例如：

`成本优势 × 性能优势 × 认证周期 × 样本积累 = 复合竞争优势`

遵守以下边界：

- 等号右侧是定性结论时，允许跨量纲组合；
- 等号右侧是具体数字时，计算和量纲必须成立；
- CAGR、增长倍数、市场份额等常规财务计算必须自洽；
- 同一数字跨页出现时必须统一，或明确标注约数、FA测算或不同口径。

### 5. FA上行情景

主动构建有进攻性的上行情景，例如目标市场份额、利润率提升、数据领先窗口或平台扩张，但不得把目标伪装成已发生事实。

每个情景都要给出实现路径或公式：

- `目标份额 = 头部客户覆盖 × 单客户渗透 × 留存/扩品率`
- `领先窗口 = 样本采集周期 + 客户验证周期 + 迭代周期`

明确百分比、百分点、毛利率/净利率、基准对象、目标年份和适用市场，避免模糊口径。

## 数字身份纪律

在大纲后台和DD材料表中给重要数字标记身份：

- `[事实]`：已验证，注明来源和日期；
- `[推断]`：由事实计算，展示关键假设或公式；
- `[FA上行情景]`：有条件的进攻性目标，展示实现路径；
- `[待研究]`：决定叙事但尚缺严谨证据。

数字可以大胆，身份不能含糊。页面只在历史事实与预测、推断或FA情景可能混淆时显式显示身份；其他身份保留在后台和DD材料表。禁止编造当前事实、伪造来源或把预测写成已实现结果。

## BP与DD材料表分工

BP只展示建立兴趣、确信和行动所需的证据。为每个重要主张维护DD材料表，至少记录：

| 字段 | 内容 |
|---|---|
| 对应页面 / 主张 | 该材料支撑哪一页、哪句话或哪个数字 |
| 数字身份 | 事实 / 推断 / FA上行情景 / 待研究 |
| 完整来源与日期 | 报告、合同、订单、访谈、数据库或公司材料 |
| 计算与口径 | 起止年份、周期、公式、单位、区域和关键假设 |
| 保密状态 | 可公开 / 匿名展示 / 仅尽调披露 / 禁止对外 |
| 证据状态 | 已取得 / 可取得 / 待补 |
| 追问接法 | 投资人追问时可回答到什么程度、下一步提供什么材料 |

不要根据上下文恢复被遮挡的客户名称、合同金额、地点或机构关系。匿名、区间、占位符和掩码必须原样保留。

## 研究任务抛回机制

当胜负手页面依赖最新市场规模、竞对估值/融资/并购、严谨产业趋势或高概率被追问的数据时：

1. 先用现有材料和可用知识库确定具体研究对象；
2. 继续交付带 `[待研究]` 占位的大纲 v0，不让整套工作停摆；
3. 向用户抛出精确报告任务，不抛开放式大题；
4. 收到报告后更新对应页面和核心叙事。

报告任务格式：

```text
研究任务 R{N}
主题：
本报告要证明：
必须回答：3–6个具体问题
时间/地域/口径：
优先来源：
期望产出：表格、图、关键原文或案例
解锁页面：
```

只有会改变投资判断的缺口才触发报告任务；装饰性数字不值得单独研究。

## 容器与容器外文本纪律

本节为普通内页通用规则；资本封面、投资亮点总览、竞争力目录等专用页面格式优先于本节。资本封面允许一行资本凭证带，但禁止公司介绍式副标题和产品说明。

### 容器定义与数量

- 每页最多 5 个主内容容器。
- 主内容容器包括卡片、表格、面板、图表，以及由共同主轴、边界或阅读逻辑收束的时间轴、流程图和比较结构。
- 同一表格的单元格、同一时间轴的阶段、同一图表的系列，不分别计作容器；判断标准是它们是否共享一个明确的结构，而不是是否各自带框。
- 标题块、Logo/公司名、页码和来源底注不计入主内容容器。结论带最多一个，可作为结构带使用，但不得再承载一组新的并列证据。
- 内容无法收束在 5 个容器内时，优先合并为表格、时间轴、矩阵或组合图；仍然拥挤则拆页，不把信息拆成更多小卡片。

### 容器外文本白名单

- 页面主内容区之外只允许：
  1. 一个标题块：标题，加可选的一句副标题；
  2. Logo/公司名与页码；
  3. 来源和必要底注；
  4. 可选一个结论句，且优先放入结论带，不悬空。
- 所有关键数字、核心断言、解释段落、模块标题和图注，必须进入某个主内容容器，或直接绑定到同一图表、时间轴或流程节点。
- 图表轴、刻度、节点日期和紧邻图形的短标签，视为结构内文本；游离在空白区、无法明确归属于某一结构的数字或说明，视为容器外文本。
- 禁止在页顶、页中、页底同时铺设多组裸排指标、独立小标题、图标加说明或悬浮结论。页面应呈现“少量外部标题 + 内部高密度结构”，而不是“容器周围再散落一层文本”。
- 正向结构：标题与副标题在外，主要信息集中在 1–5 个表格、阶段卡、应用面板或其他共同结构内。
- 反向结构：顶部多组指标裸排，中部另放游离大数字或结论，底部再铺流程卡，形成三层以上互不收束的文本区。

## 投资亮点总览：用传统容器建立证据组合

投资亮点总览是特殊页面；一旦采用，必须在一页内同时覆盖市场上限、技术稀缺性、商业兑现和团队可信度四类证据，快速建立全局确信。它不是把后续页面缩成目录，也不是四项优势的形容词合集，而是一组经过筛选的证据入口。

### 选择规则

- 固定设置市场上限、技术稀缺性、商业兑现和团队可信度四个模块，不得删减类别。某一类证据不足时显式标记 `[待补数据]`，不得用弱事实或形容词凑数。
- 每个模块只回答一个尽调问题，并采用：
  `短结论 → 1–3条证明`
- 页面标题先综合各模块，形成一条完整投资判断，优先采用：
  `产业触发 → 新赛道/窗口 → 项目凭什么赢 → 财务或商业结果`
- 四张卡允许各自设置一个受控钩子，由页面标题统一投资逻辑；每张卡不得再堆第二个主数字或主断言。
- 只选最强证据。若一条内容需要超过 3 个短点才能讲清，说明它应拆成独立页面，不应塞入总览。

### 信息容器原则

- 统一的是容器身份、编号、标题基线和阅读顺序；变化的是证据表达，可分别采用数字、产品/技术断言、迷你图表、能力方程或凭证条。四卡可以等权，也可以让市场卡略强；不得在单卡内部形成第二个视觉中心。
- 模块顺序应构成投资逻辑，推荐：
  `机会有多大 → 为什么能做 → 是否已兑现 → 谁来兑现`
- 不要把弱事实包装成并列亮点；四个模块必须保留，证据不足的模块明确标记 `[待补数据]`。

适用输出示例：

```text
### P{N} · 投资亮点总览
- 投资任务：用一页建立市场、能力、兑现与团队的组合确信
- 核心结论：
- 标题：产业触发 → 新机会 → 项目能力 → 商业结果
- 模块1：市场证据 | 短结论；1–2条证明
- 模块2：技术证据 | 短结论；1–3条证明
- 模块3：兑现证据 | 短结论；增长或客户证明
- 模块4：团队证据 | 短结论；能力组合；1–2条资历证明
- 容器规划：4 个主内容容器（≤5）| 市场、技术、兑现、团队各承担一种证据职责
- 容器外文本：标题块；Logo/页码；底注；可选结论带
- 数字身份：
- 受控钩子：市场 / 技术 / 商业 / 团队各一个；每卡只保留一个主数字或主断言
- 页面模式：投资亮点总览
- 投资人追问：
- 底注：
- 待补数据：
```

## 融资披露红线

- 融资页默认只披露融资额与资金用途。
- 不主动展示投前/投后估值、估值区间、出让比例、单价或可反推估值的信息。
- 不主动补充轮次、交易结构和投资人权益；用户明确提供并要求展示时再处理。
- 可用商业模式、生态位、资产属性和资本市场对标建立价值想象，但不落到本项目当前估值计算。

## 交付规则

大纲后必须附：

1. 核心投资叙事一句话；
2. 整 deck 确信递进与节奏总览；
3. 投资委员会六问覆盖检查；
4. 胜负手页面与可将就页面；
5. 待补数据和研究任务清单；
6. 最可能击穿叙事的 3 个投资人反问；
7. DD材料表，覆盖重要主张的来源、计算、保密状态、证据状态和追问接法。

用户要求换一版时，换投资切角、证据顺序或价值终局，不只换措辞。

## 常见死法

- 用消费者痛点替代投资逻辑；
- 封面堆产品说明、使命愿景和长副标题，资本标签反而不突出；
- 封面遗漏融资轮次，或为了凑齐类别塞入不亮眼的弱标签；
- 强行反共识，证据却支撑不住；
- 只放巨大 TAM，却不解释市场扩大的产业变量或形成原因；
- 把性能领先直接叫护城河；
- 把 FA 情景或预测伪装成事实；
- 用形容词代替数字、机制和路径；
- 把公司大事记误当能力沿革，只列年份却没有继承与升级；
- 用连续线或机构 Logo 暗示未经证实的技术转让、背书或隶属；
- 技术架构只服务 CTO 自嗨，不解释客户价值；
- 披露或反推本项目当前估值；
- 普通证据页堆多个记忆锚点，导致没有焦点；投资亮点四卡和竞争力目录按专用规则执行。
- 把投资亮点总览写成四项同质化口号，或为了四栏对称硬凑弱证据。
- 在单张投资亮点卡内堆叠两个以上主数字或主断言。
- 把传播型公式的定性结果伪装成可计算的定量结果。
- CAGR、增长倍数、市场份额、坐标轴或跨页重复数字彼此不自洽。
- 擅自恢复被掩码或匿名处理的客户、金额、地点和机构关系。
- 主内容容器超过 5 个，或把一个完整结构拆成大量小卡片；
- 标题区之外散落关键数字、模块标题、说明段落或图注，形成多层游离文本；
- 同时在页顶、页中、页底堆叠多组容器外结论，使结构失焦。
